# Game Rig Tools - Dance animations version

Upstream: TinkerBoi / CGDive, https://tinkerboi.com/ and
https://cgdive.notion.site/Game-Rig-Tools-Documentation-dc61839fd1d04147a42aa89e366575fb.

This is the modified 4.3.0 version from SanjoSolutions/a-game, maintained for
Dance animations. The complete Python source is included in the repository and
installation ZIP. The upstream authors retain their copyrights. Distribution
uses GPL version 3, a version allowed by the original GPL-2.0-or-later manifest.
The supplied GPL version 3 LICENSE and original changelog are retained.

Modifications inherited from a-game include native multi-rig bake pairs,
dependency-graph evaluation before visual-key baking, overwrite handling,
NLA naming, the rig-pair interface, and configured Godot export handling.
The bundled Changelog.md documents these changes. These adaptations precede
the October 2026 import into Dance animations. The Dance animations package
includes this notice, uses a distinct display name, and shortens the manifest's
tagline to meet Blender's extension validation limit.
