# Dance animations

Free dance animations.

[Open the animation library](https://sanjosolutions.github.io/dance-animations/).

Each of the 92 styles includes human-composed music by Kevin MacLeod, available
as a WAV excerpt under CC BY 4.0 with attribution. The player and credits page
include the composer, recording source, license, and adaptations. **Music** is
on by default at 50% volume; **Play** starts audio when the browser requires a user gesture.
Music and motion share pause, restart, seek,
and loop controls. Music keeps its recorded tempo and pitch; animation timing
adapts to the recording. The preview speed control applies to silent playback.
Move changes within a style keep the music playing and begin the next move
on the first beat of a musical measure.
**Playback mode** offers Single, Sequential, and Random (the default), with the next move
preloaded. House defaults to 16 bars per move; each style's interval is
configurable. Playback mode is included in the URL and browser history.
Music, volume, Playback mode, and per-style intervals are remembered in local storage.
See [music timing and provenance](docs/music.md) for the synchronization rules
and recording preparation workflow. Related styles share suitable recordings;
broader rhythm matches carry a practice accompaniment label.

Animations have been initially generated with OpenAI Astra (High). They might contain errors. Improvement PRs and error reports are welcomed.

Right now many of the animations contain errors of various degrees. The idea is that someone can fix them either manually or via capable models like OpenAI Astra and then contribute the fixes back, so the work is only required to be done once. I have generated the initial animations with a weekly Pro 20x usage and might contribute further improvements as I find spare usage.
